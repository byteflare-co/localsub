# Changelog

All notable changes to LocalSub will be documented in this file. The project follows
[Semantic Versioning](https://semver.org/).

## [Unreleased]

## [0.1.0-alpha.2] - 2026-08-12

### Added

- An opt-in, privacy-bounded CLI update notice for Homebrew and installer users.
- Public release verification for the immutable source archive, installer, Formula lifecycle,
  and synthetic-video dogfood run.

### Fixed

- Release read-back compatibility with the installed GitHub CLI version.

## [0.1.0-alpha.1] - 2026-08-12

### Added

- Native macOS desktop and CLI workflows for Japanese caption generation.
- Optional English-to-Japanese translation using Apple Translation or GPT-5.6 Luna.
- Editable two-line captions, burned-in MP4 export, and UTF-8 SRT export.
- Apache-2.0 licensing and open-source contribution infrastructure.
- A public, source-built CLI distribution through Homebrew and a verified installer.
