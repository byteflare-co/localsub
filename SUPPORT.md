# Support

LocalSub is currently an early-stage open-source project.

- Usage questions and reproducible bugs: open a GitHub Issue using the appropriate template.
- Feature proposals: use the feature request template and explain the problem before the solution.
- Security vulnerabilities: follow [SECURITY.md](SECURITY.md) and use private vulnerability
  reporting. Do not post exploit details publicly.
- Commercial support or a signed distribution inquiry: use the
  [株式会社Byteflare contact form](https://byteflare.co/contact/).

Please do not include private video, audio, transcripts, API keys, or signing credentials in an
issue. Reduce media problems to a synthetic fixture whenever possible.
