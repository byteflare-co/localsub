# LocalSub CLI v0.1.0-alpha.1

LocalSub CLIの最初のアルファリリースです。Apple SiliconとmacOS 26以降を対象に、動画内の
日本語または英語音声から、編集可能な日本語字幕と字幕付きMP4を生成します。

## 主な機能

- Apple Speechによる端末内文字起こし
- 日本語音声から日本語字幕を生成
- 英語音声をApple Translationまたは任意のGPT-5.6 Lunaで日本語化
- 用語集、2行字幕、MP4書き出し
- `doctor`、明示同意付きSpeechモデル`setup`
- Developer ID署名、公証、チェックサム検証付き配布

## 対応環境

- Apple Silicon
- macOS 26以降

これはアルファ版です。機密動画で利用する前に、短い非機密動画で結果を確認してください。
