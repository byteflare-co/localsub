# LocalSub CLI v0.1.0-alpha.2

Homebrewで一般提供したLocalSub CLIに、控えめな更新通知を追加するアルファリリースです。

## 変更点

- `localsub update-check enable --acknowledge-metadata`で明示的に有効化した場合だけ、最大24時間に1回確認
- 新しいバージョンがある場合だけ標準エラーへ通知
- 更新は自動適用せず、`brew upgrade byteflare-co/tap/localsub`を案内
- `localsub update-check disable`で同意を撤回可能
- `--help`と`--version`は常にネットワークアクセスなし
- `LOCALSUB_NO_UPDATE_CHECK=1`で有効な確認を一時停止可能
- redirect、応答サイズ、timeout、release URLとversionをfail-closedで検証

## 対応環境

- Apple Silicon
- macOS 26以降
- Xcode 26以降

更新確認は既定で無効です。有効化しても動画、音声、字幕、翻訳、ファイル名、パス、APIキーを送信しません。
